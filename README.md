# WeVote 群投票

用于 AstrBot 的 QQ / OneBot v11 群聊投票插件。支持单选、多选及选择数量上限、同群多个投票、独立改票指令、公开或保密统计、到期结算与重启恢复。

## 安装

1. 在 AstrBot 中配置并连接 QQ / OneBot v11 平台，平台类型为 `aiocqhttp`。
2. 在插件管理中上传 `dist/astrbot_plugin_wevote.zip`，或将源码放入 `data/plugins/astrbot_plugin_wevote/`，确保 `main.py`、`metadata.yaml`、`_conf_schema.json` 和 `wevote/` 直接位于插件目录内。
3. 重新加载插件，并在插件配置中设置 `initiator_whitelist`（可为空）。
4. 在群中发送 `/投票` 查看帮助。若修改过 AstrBot 唤醒前缀，请使用对应前缀或 @机器人唤醒命令。

运行时只依赖 Python 标准库与 AstrBot，不需额外 pip 包。当前没有配置 Git 远程地址；发布仓库后可将真实地址填入 `metadata.yaml` 的 `repo` 字段，以支持通过仓库安装和更新。

## 权限

以下用户可以发起、提前结束、取消本群投票，并请求本群保密投票的统计：

- QQ 群主和群管理员：根据当前 OneBot 入站事件的 `sender.role` 判断。
- AstrBot 管理员：根据 AstrBot 的管理员配置判断。
- `initiator_whitelist` 中的 QQ 用户：白名单对所有接入群生效。

其他群成员可以参与、改票、查看投票基本信息及列出进行中的投票。白名单配置示例：

```json
{
  "initiator_whitelist": ["123456789", "987654321"]
}
```

白名单直接在 AstrBot 插件配置中维护。若 OneBot 未提供群角色且用户不具备其他授权，不授予管理权限。首版只支持 QQ / OneBot v11 群聊。

## 发起投票

```text
/投票 发起 10m 单选 公开 午饭吃什么 | 米饭 | 面条
/投票 发起 2h 多选2 保密 周末活动 | 电影 | 爬山 | 聚餐
```

格式：`/投票 发起 时长 模式 公布策略 题目 | 选项1 | 选项2 ...`

| 参数 | 规则 |
| --- | --- |
| 时长 | 正整数加 `s` / `m` / `h`，如 `30s`、`10m`、`2h`；范围 1 秒至 7 天 |
| 模式 | `单选`，或 `多选N`；N 为 2 至选项数量，多选可少选但至少选一项 |
| 公布策略 | `公开` 或 `保密` |
| 题目 | 1 至 200 个字符 |
| 选项 | 2 至 20 个，每项 1 至 100 个字符，不可为空或重复 |

题目和选项可以有空格；`|` 是分隔符，内容不能包含该字符。成功发起后会返回投票 ID、编号选项和截止时间。截止时间明确显示为 UTC。

## 投票与改票

假设投票 ID 为 `12`：

```text
/投票 选择 12 1
/投票 选择 12 1 3
/投票 改票 12 2 3
```

首次投票必须用“选择”。重复使用“选择”不会覆盖原票，会提示使用“改票”。未投过票的用户不能改票。改票整体替换原选择；无效编号、重复编号或超过选择上限时，原票保持不变。

同一用户在每个投票中只算一名参与者。每个选项的比例为选择该项的人数除以总参与人数；多选时各项比例合计可能超过 100%。公开结果包含零票选项、最高票和并列最高票；没有人参与时不会把所有零票选项当成并列获胜者。不公开投票人的 QQ 号。

## 查看和管理

```text
/投票 查看 12
/投票 列表
/投票 结束 12
/投票 取消 12
```

“列表”显示本群进行中的投票。“查看”也可以查询已结束的投票。投票 ID 持久化且不复用，同群允许多个进行中的投票；不同群、平台实例与机器人身份的状态隔离，不能通过 ID 操作其他群的投票。开启 AstrBot 群聊独立用户会话也不会将同群计票拆开。

“结束”提前结算；“取消”只发取消通知，不公布统计。这两种操作均由当前具备发起权限的用户执行，不限定必须是原发起人。

| 模式 | 普通群成员查看 | 授权用户查看 | 到期群内通知 |
| --- | --- | --- | --- |
| 公开 | 基本信息、实时票数、比例、最高票/并列 | 同左 | 完整结果 |
| 保密 | 题目、选项、截止时间、参与人数 | 群内基本信息；具体统计通过私聊发送 | 只通知已结束 |

保密统计通过 OneBot 私聊 API 发送给查询人。机器人需能向该用户私聊（通常需要添加好友）；发送失败会在群内提示重试，不会将统计回退发送到群内。取消后的投票不再展示统计。

## 定时结算与恢复

- SQLite 数据保存在 `data/plugin_data/astrbot_plugin_wevote/votes.sqlite3`，包括投票内容、参与用户 ID、选择、截止时间及通知状态。保密控制的是聊天消息中的统计披露，不是数据库加密；有服务器文件访问权的人能读取这些数据。
- 插件启动时立即检查到期投票，随后每 5 秒检查一次。正常情况下到期后在下一轮发送结果；平台发送延迟或失败会延后通知。
- 投票和改票操作直接检查截止时间，截止时刻起拒绝新票，即使定时任务尚未发送结果。
- 重启会恢复未结束的投票，并补结算停机期间已到期的投票。平台返回失败或抛出异常时保留待发送通知，后续重试；单次发送超时为 30 秒。
- 正常情况下通知成功后标记已发送，后续不再重复。发送与数据库提交无法形成同一事务：发送后若进程在保存通知状态前崩溃，恢复时可能重复通知。API 成功返回也不能证明 QQ 客户端最终收到消息。
- 插件停止时取消并等待定时任务，再关闭数据库；停止期间不计时推送，重启后补结算。投票记录保留用于查询。

```powershell
python -X utf8 -m unittest discover -s tests -v
python -m compileall -q main.py wevote tests scripts
python scripts/package.py
git diff --check
```

自动测试使用临时 SQLite 数据库和 AstrBot 接口替身，覆盖输入校验、管理权限、单选多选、独立改票流程、时间边界、群隔离、保密私聊、失败重试、生命周期和重启补结算。它们不能替代真实 AstrBot / QQ 群聊验证。

打包脚本只打包运行所需文件与本说明，不包含测试、规划文档、Git 数据、运行数据或缓存；`dist/` 被 Git 忽略。
